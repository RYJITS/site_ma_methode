# Installation - SITE MA METHODE

```powershell
git clone https://github.com/RYJITS/site_ma_methode.git
cd site_ma_methode
```

```powershell
npm install
npm run check
npm run dev
```

Avant publication, suivre [la checklist de déploiement](DEPLOIEMENT_CHECKLIST_FR.md), puis exécuter `npm test` et `npm run deploy:check`.
Les deux publications https://cv.c2rdesign.com/ et https://c2rdesign.com/ sont maintenues jusqu’à nouvel ordre, via le MCP Hostinger après audit et hostinger:check.
