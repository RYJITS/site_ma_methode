# DATACHECK

## Projet
Bibliothèque de fiches dans l’interface Prisme Studio : recherche, filtres, lecture des sources et suivi des validations. Une démonstration autonome permet de l’installer sans compte.

## A quoi il sert
DATACHECK est une bibliothèque de fiches avec recherche, filtres et lecteur de sources. L’interface Prisme Studio présente les ressources par type et permet d’examiner les scores et les limites de leur validation. La distribution GitHub comprend le code et trois exemples entièrement synthétiques, affichés comme non vérifiés.

## Fonctions
- Bibliothèque de fiches
- Recherche et filtres
- Lecture détaillée
- Sources et scores de validation
- Génération depuis des fichiers TXT
- Démonstration synthétique autonome
- Import et classement locaux
